# **Détection de Battements avec Raspberry Pi Pico W**

Ce projet utilise MicroPython pour détecter les battements d’une musique via un microphone et changer la couleur d’une LED RGB WS2812.

## **Objectif**

Lire en continu les données du microphone.
Détecter les battements sonores.
Changer la couleur de la LED à chaque battement.

## **Bonus**

Calculer le rythme en BPM.
Enregistrer la moyenne des BPM par minute dans un fichier texte.

## **Matériel**

Raspberry Pi Pico W
Microphone analogique
LED RGB WS2812
